## Context

SDDP policies are trained on specific scenario samples (SAA). Production use requires confidence that policies **generalize** to unseen scenarios. Out-of-sample (OOS) testing validates policy robustness to distribution shift and sampling variation.

**Current State**:

- Training uses fixed scenario samples (SAA with seed)
- Simulation typically uses same or similar scenarios
- No infrastructure for OOS testing
- No tests for policy generalization

**Need**: Infrastructure to test policies on different scenarios than training, measure generalization, and detect overfitting.

**Key Questions**:

1. Does policy trained on N scenarios work well on independent M scenarios?
2. How sensitive is policy to distribution parameters (σ changes)?
3. Does policy degrade gracefully with distribution shift?
4. What's the optimal balance between training scenarios and OOS performance?

## Technical Notes

### Implementation Approach

**Independent Scenario Generation**:

```rust
pub struct OOSGenerator {
    base_seed: u64,
    system: System,
}

impl OOSGenerator {
    pub fn generate_independent(&self, num_scenarios: usize) -> Vec<Scenario> {
        // Use independent seed (base_seed + large offset)
        let oos_seed = self.base_seed.wrapping_add(1_000_000);
        let mut rng = StdRng::seed_from_u64(oos_seed);

        // Generate scenarios using same distributions but independent samples
        self.system.generate_scenarios(num_scenarios, &mut rng)
    }

    pub fn scale_shift(&self, scale: f64) -> Vec<Scenario> {
        // Generate scenarios with scaled variance
        let oos_seed = self.base_seed.wrapping_add(2_000_000);
        let mut rng = StdRng::seed_from_u64(oos_seed);

        self.system.generate_scenarios_with_scale(num_scenarios, scale, &mut rng)
    }
}
```

**Statistical Independence Verification**:

```rust
// Use two-sample Kolmogorov-Smirnov test
fn verify_independence(training: &[f64], oos: &[f64]) -> bool {
    let ks_statistic = compute_ks_statistic(training, oos);
    let p_value = ks_test_p_value(ks_statistic, training.len(), oos.len());
    p_value > 0.05  // Fail to reject independence hypothesis
}
```

### Edge Cases

1. **Deterministic problems**: OOS = in-sample (gap should be ~0)
2. **Extreme overfitting**: Gap can be arbitrarily large
3. **Distribution shift**: Policy may become infeasible (acceptable)
4. **Very small training samples**: High variance in OOS estimates

### Performance Considerations

- **Scenario generation**: Reuse existing generators, just with different seeds
- **OOS evaluation**: Same as regular simulation (no overhead)
- **Statistical tests**: Compute only when explicitly requested (optional)

### Statistical Independence

**Kolmogorov-Smirnov Test**:

- Null hypothesis: Two samples from same distribution
- Test statistic: max difference in empirical CDFs
- Use `statrs` crate for implementation

**Expected Results**:

- Training vs OOS: p-value > 0.05 (independent)
- Training vs training: p-value ≈ 1.0 (same distribution)

### OOS Metrics

**Generalization Gap**:

- Gap = OOS_cost - InSample_cost
- **Good**: Gap < 5% (policy generalizes well)
- **Acceptable**: Gap ∈ [5%, 15%] (minor overfitting)
- **Poor**: Gap > 15% (significant overfitting)

**OOS Ratio**:

- Ratio = OOS_cost / InSample_cost
- **Good**: Ratio ∈ [0.95, 1.05]
- **Acceptable**: Ratio ∈ [0.90, 1.10]
- **Poor**: Ratio outside [0.85, 1.15]
