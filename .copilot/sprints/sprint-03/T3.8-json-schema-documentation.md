## Context

Input JSON format is documented informally (examples, comments). Users would benefit from **formal JSON schema** for validation, IDE auto-completion, and comprehensive documentation.

**Current State**:

- Input format documented in examples
- No formal schema
- No schema validation tools
- IDEs cannot provide auto-completion

**Need**: Formal JSON schema for all input files (graph.json, recourse.json, system.json, config.json).
