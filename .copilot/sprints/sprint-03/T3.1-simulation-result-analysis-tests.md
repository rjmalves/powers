## Technical Notes

### Implementation Approach

**Trajectory Storage**:

```rust
pub struct Trajectory {
    pub stages: Vec<StageResult>,
    pub total_cost: f64,
    pub scenario_id: usize,
}

pub struct StageResult {
    pub stage: usize,
    pub state: Vec<f64>,
    pub action: Vec<f64>,  // generation, spillage, etc.
    pub stage_cost: f64,
    pub inflow: Vec<f64>,   // realized inflow
    pub load: Vec<f64>,     // realized load
}
```

**Statistics Computation**:

- Use `rayon` for parallel statistics computation on large trajectory sets
- Compute percentiles efficiently with `select_nth_unstable` (O(n))
- Bootstrap confidence intervals: resample trajectories 1000 times, compute mean each time

### Edge Cases

1. **Zero scenarios**: Return error or empty result
2. **Single scenario**: Statistics are trivial (mean = cost, CI undefined)
3. **Many scenarios (>10,000)**: Use streaming statistics to avoid memory issues
4. **Simulation before training**: Should work (no cuts, just system dynamics)

### Performance Considerations

- **Trajectory storage**: Store references to avoid copying state
- **Statistics computation**: Parallel computation with `rayon`
- **Memory**: Pre-allocate trajectory vectors
- **Confidence intervals**: Cache bootstrap samples to avoid recomputation
