## Description

Create comprehensive unit tests for the `BendersCutPool` and related cut storage/selection logic in `src/fcf.rs`. The cut pool is responsible for storing cuts efficiently, tracking active cuts, and selecting which cuts to use in subproblems. This is critical for algorithm performance and correctness.

## Context

The Future Cost Function (FCF) module manages the collection of cuts that approximate the expected future cost. Key responsibilities:

- Store cuts efficiently (avoid duplicates, remove dominated cuts)
- Track which cuts are "active" (binding at recent states)
- Select cuts to add to subproblems (active set strategy)
- Compute lower bound approximation at any state

Testing should verify both correctness and performance characteristics.

## Technical Notes

### Key Properties to Test

1. **Correctness**:

   - **Retrieval**: Added cuts can be retrieved correctly
   - **Active Tracking**: Active set reflects recently binding cuts
   - **Lower Bound**: Approximation is correct maximum of cuts
   - **Selection**: Selected cuts form valid approximation

2. **Performance**:

   - **Bounded Growth**: Pool size doesn't grow indefinitely
   - **Efficient Lookup**: Cut selection is fast even with many cuts
   - **Memory**: No memory leaks or excessive allocation

3. **Invariants**:
   - Active set ⊆ all cuts
   - Lower bound ≥ any single cut value
   - Selected cuts non-empty (unless pool empty)

### Test Examples

```rust
#[test]
fn test_add_and_retrieve_cuts() {
    let mut pool = BendersCutPool::new();

    let cut1 = create_test_cut(vec![1.0], 10.0);
    let cut2 = create_test_cut(vec![2.0], 20.0);

    pool.add_cut(cut1.clone());
    pool.add_cut(cut2.clone());

    assert_eq!(pool.len(), 2);
    // Verify cuts can be retrieved
}

#[test]
fn test_active_set_tracking() {
    let mut pool = BendersCutPool::new();

    // Add several cuts
    for i in 0..10 {
        pool.add_cut(create_test_cut(vec![i as f64], i as f64));
    }

    // Mark some as active
    let state = vec![5.0];
    pool.update_active_cuts(&state);

    // Verify active set is non-empty and reasonable
    let active = pool.get_active_cuts();
    assert!(!active.is_empty());
    assert!(active.len() <= pool.len());
}

#[test]
fn test_lower_bound_is_maximum() {
    let mut pool = BendersCutPool::new();

    let cut1 = BendersCut::new(vec![0.0], vec![1.0], 10.0).unwrap();
    let cut2 = BendersCut::new(vec![0.0], vec![2.0], 5.0).unwrap();

    pool.add_cut(cut1.clone());
    pool.add_cut(cut2.clone());

    let state = vec![5.0];
    let lb = pool.lower_bound_at(&state);

    // Should be max of individual cuts
    let lb1 = cut1.intercept_at(&state);
    let lb2 = cut2.intercept_at(&state);
    assert_float_approx_eq!(lb, lb1.max(lb2), 1e-10);
}
```
