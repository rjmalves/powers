## Description

Create comprehensive unit tests for the Benders cut operations defined in `src/cut.rs`. This includes testing cut creation, validation, intercept calculation, coefficient operations, and numerical stability. The cut is a fundamental data structure in SDDP, so thorough testing is critical.

## Context

The `BendersCut` struct represents the affine approximation of the future cost function. It has the form:

```
θ >= intercept + coefficients^T * (state - reference_state)
```

Key operations to test:

- Cut creation and validation
- Intercept calculation at different states
- Coefficient operations (dot products, norms)
- Numerical properties (convexity, validity)
- Edge cases (zero coefficients, extreme values)

## Technical Notes

### Key Properties to Test

1. **Mathematical Properties**:

   - **Affinity**: `intercept(state) = base_intercept + coeff^T * (state - ref_state)`
   - **Convexity**: Cut represents lower bound (assuming minimization)
   - **Validity**: Coefficients match state space dimension

2. **Numerical Properties**:

   - **Stability**: No catastrophic cancellation
   - **Robustness**: Handles extreme values gracefully
   - **Precision**: Intercept calculation accurate to reasonable tolerance

3. **Invariants**:
   - Cut at reference state equals base intercept
   - Cut is linear (affine) in state variables
   - Coefficients remain unchanged after intercept calculations

### Test Examples

```rust
#[test]
fn test_cut_creation_valid() {
    let reference_state = vec![100.0, 200.0];
    let coefficients = vec![1.5, -0.5];
    let intercept = 42.0;

    let cut = BendersCut::new(reference_state, coefficients, intercept);

    // Should create successfully
    assert!(cut.is_ok());
}

#[test]
fn test_intercept_at_reference_state() {
    let reference_state = vec![100.0];
    let coefficients = vec![2.0];
    let intercept = 10.0;

    let cut = BendersCut::new(reference_state.clone(), coefficients, intercept).unwrap();
    let calculated_intercept = cut.intercept_at(&reference_state);

    // At reference state, intercept should equal base intercept
    assert_float_approx_eq!(calculated_intercept, intercept, 1e-10);
}

#[test]
fn test_cut_numerical_stability() {
    let reference_state = vec![1e10];
    let coefficients = vec![1e-10];
    let intercept = 1.0;

    let cut = BendersCut::new(reference_state, coefficients, intercept).unwrap();
    let state = vec![1e10 + 1.0];
    let result = cut.intercept_at(&state);

    // Should not produce NaN or Inf
    assert!(!result.is_nan());
    assert!(!result.is_infinite());
}
```
