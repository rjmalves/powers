# T1.7: Set up CI for automated testing

**Sprint**: 1  
**Estimate**: 4 hours  
**Priority**: High  
**Type**: Infrastructure  
**Dependencies**: T1.1-T1.6 (all tests should exist)

## Description

Set up Continuous Integration (CI) to automatically run tests on every push and pull request. This ensures code quality is maintained and regressions are caught early. Use GitHub Actions for CI/CD pipeline.

## Context

Automated testing is essential for maintaining code quality. CI should:

- Run all tests on every PR
- Block merges if tests fail
- Run on multiple Rust versions (stable, maybe nightly)
- Report test results clearly
- Be fast (<10 minutes for full test suite)

## Acceptance Criteria

- [ ] GitHub Actions workflow created and working
- [ ] Tests run automatically on push to main and all PRs
- [ ] CI fails if any test fails
- [ ] CI runs on Rust stable
- [ ] Test results visible in PR checks
- [ ] CI completes in <10 minutes
- [ ] Documentation updated with CI badge

## Technical Notes

### GitHub Actions Workflow Structure

```yaml
name: Tests

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  CARGO_TERM_COLOR: always

jobs:
  test:
    name: Run Tests
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Install Rust
        uses: actions-rs/toolchain@v1
        with:
          profile: minimal
          toolchain: stable
          override: true

      - name: Cache cargo registry
        uses: actions/cache@v3
        with:
          path: ~/.cargo/registry
          key: ${{ runner.os }}-cargo-registry-${{ hashFiles('**/Cargo.lock') }}

      - name: Cache cargo index
        uses: actions/cache@v3
        with:
          path: ~/.cargo/git
          key: ${{ runner.os }}-cargo-git-${{ hashFiles('**/Cargo.lock') }}

      - name: Cache cargo build
        uses: actions/cache@v3
        with:
          path: target
          key: ${{ runner.os }}-cargo-build-target-${{ hashFiles('**/Cargo.lock') }}

      - name: Install system dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y cmake build-essential

      - name: Run tests
        run: cargo test --all-features --verbose

      - name: Check formatting
        run: cargo fmt --all -- --check

      - name: Run clippy
        run: cargo clippy --all-targets --all-features -- -D warnings
```

### Key Features

1. **Triggers**:

   - Push to main branch
   - All pull requests targeting main

2. **Test Stages**:

   - Compile (with caching)
   - Run all tests
   - Check formatting (cargo fmt)
   - Run linter (clippy)

3. **Caching**:

   - Cargo registry and git index
   - Build artifacts
   - Speeds up subsequent runs significantly

4. **Dependencies**:
   - HiGHS requires cmake and build-essential
   - Install system dependencies before building

### CI Optimization Tips

1. **Caching**: Use GitHub Actions cache for dependencies
2. **Parallelism**: Tests run in parallel by default
3. **Fail Fast**: Stop on first failure to save time
4. **Selective Testing**: Can add filters if needed later

- **Risk**: Flaky tests may cause CI failures
  - **Mitigation**: Ensure tests are deterministic (from previous tickets)
