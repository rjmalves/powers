## Technical Notes

### Example Test Problem: Simple Reservoir

**Problem**: Manage a reservoir over 2 stages to maximize expected hydropower revenue.

**Stage 1**:

- Decide how much water to release (generate power)
- Revenue = price \* release
- Reservoir transitions: level(t+1) = level(t) - release(t) + inflow(t)

**Stage 2**:

- Inflow is stochastic (3 scenarios: dry, average, wet)
- Decide final release to maximize revenue
- Terminal value: prefer full reservoir

**Expected Solution**:

- First stage should balance current revenue vs future value
- Policy should release less in dry scenarios, more in wet
- Can compute expected value via backward induction

### Test Structure

```rust
#[test]
fn test_sddp_simple_2stage_reservoir() {
    // 1. Set up problem
    let system = create_simple_2stage_reservoir();
    let scenarios = create_2stage_scenarios(); // 3 scenarios
    let config = SDDPConfig {
        max_iterations: 50,
        tolerance: 1e-4,
        seed: Some(42), // Deterministic
        ..Default::default()
    };

    // 2. Run SDDP
    let mut sddp = SDDP::new(system, scenarios, config);
    let result = sddp.solve();

    // 3. Validate convergence
    assert!(result.converged);
    assert!(result.iterations <= 50);
    let gap = (result.upper_bound - result.lower_bound) / result.upper_bound;
    assert!(gap < 0.01); // 1% gap

    // 4. Validate solution quality
    let expected_value = 42.0; // Compute analytically or via reference
    assert_float_approx_eq!(result.upper_bound, expected_value, 1.0);

    // 5. Validate policy makes sense
    let first_stage_decision = result.policy.decision_at(stage=0, state=initial_state);
    assert!(first_stage_decision >= 0.0);
    assert!(first_stage_decision <= initial_reservoir_level);
}
```
