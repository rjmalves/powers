## Description

Create comprehensive unit tests for state variable management logic in `src/state.rs`. This includes testing state transitions, bound enforcement, state space coverage tracking, and state representation. States are the decision variables that link stages in SDDP, so correct state handling is fundamental.

## Context

State variables in SDDP represent the physical state of the system (e.g., reservoir levels) that transitions from one stage to the next. Key aspects:

- **Bounds**: States must respect physical constraints (min/max levels)
- **Transitions**: States evolve based on decisions and random events
- **Dimensionality**: Multi-dimensional state spaces must be handled correctly
- **Validation**: Invalid states should be detected and handled

Testing should ensure states are always valid and transitions preserve physical meaning.

### Test Examples

```rust
#[test]
fn test_state_creation_valid() {
    let bounds = StateBounds::new(vec![0.0], vec![100.0]);
    let state = State::new(vec![50.0], bounds.clone());

    assert!(state.is_ok());
    assert!(state.unwrap().is_within_bounds());
}

#[test]
fn test_state_clamping() {
    let bounds = StateBounds::new(vec![0.0], vec![100.0]);
    let state = vec![150.0]; // Above max

    let clamped = State::clamp(&state, &bounds);

    assert_eq!(clamped[0], 100.0);
}

#[test]
fn test_multidimensional_state() {
    let mins = vec![0.0, 10.0, -5.0];
    let maxs = vec![100.0, 50.0, 15.0];
    let bounds = StateBounds::new(mins, maxs);

    let state = vec![50.0, 30.0, 0.0];
    let s = State::new(state, bounds).unwrap();

    assert_eq!(s.dimension(), 3);
    assert!(s.is_within_bounds());
}
```
