## Context

SDDP represents uncertainty through scenario trees. Each stage has multiple scenarios, each with a probability. Key aspects to test:

- **Tree Structure**: Scenarios form valid tree (proper branching)
- **Probabilities**: Sum to 1.0 at each stage
- **Sampling**: Random scenarios follow specified distribution
- **Consistency**: Scenario properties match specification

## Technical Notes

### Key Properties to Test

1. **Structural Properties**:

   - **Valid Tree**: Proper branching, no cycles
   - **Probabilities**: Sum to 1.0 within tolerance at each node
   - **Indexing**: Consistent scenario numbering

2. **Statistical Properties**:

   - **Sampling**: Frequencies converge to probabilities
   - **Independence**: Scenarios are independent (if specified)
   - **Reproducibility**: Fixed seed gives same results

3. **Invariants**:
   - Number of scenarios per stage is consistent
   - Probabilities are non-negative
   - Total paths through tree = product of scenarios per stage

### Test Examples

```rust
#[test]
fn test_scenario_tree_probabilities_sum_to_one() {
    let tree = ScenarioTree::new_uniform(3, 5); // 3 stages, 5 scenarios each

    for stage in 0..3 {
        let probs: f64 = tree.scenarios_at_stage(stage)
            .iter()
            .map(|s| s.probability)
            .sum();

        assert_float_approx_eq!(probs, 1.0, 1e-10);
    }
}

#[test]
fn test_deterministic_scenario_tree() {
    let tree = ScenarioTree::deterministic(3); // 3 stages, 1 scenario each

    assert_eq!(tree.num_stages(), 3);
    for stage in 0..3 {
        assert_eq!(tree.scenarios_at_stage(stage).len(), 1);
        assert_eq!(tree.scenarios_at_stage(stage)[0].probability, 1.0);
    }
}

#[test]
fn test_scenario_sampling_statistics() {
    let tree = ScenarioTree::new_with_probs(
        3,
        vec![0.2, 0.3, 0.5] // Non-uniform probabilities
    );

    let n_samples = 10000;
    let mut counts = vec![0; 3];

    for _ in 0..n_samples {
        let scenario = tree.sample_scenario(0); // Sample at stage 0
        counts[scenario.index] += 1;
    }

    // Check frequencies approximately match probabilities
    for i in 0..3 {
        let freq = counts[i] as f64 / n_samples as f64;
        let expected = tree.scenarios_at_stage(0)[i].probability;
        assert!((freq - expected).abs() < 0.02); // Within 2%
    }
}
```
