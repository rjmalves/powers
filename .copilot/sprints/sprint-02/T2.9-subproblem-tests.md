## Context

Subproblem construction (`src/subproblem.rs`) is where SDDP builds stage-specific optimization problems during forward and backward passes. This is **complex logic** that:

- Constructs LP/MILP from system description
- Adds state transition constraints
- Adds cuts from future cost function
- Handles uncertainty realizations

**Current gap**: Limited testing of subproblem construction edge cases and correctness.

**Goal**: Comprehensive tests ensuring subproblems are built correctly for all scenarios.

```rust
fn test_intermediate_stage_subproblem_with_cuts() -> Result<(), String> {

    // Verify cuts are added
    assert!(subproblem.num_constraints >= fcf.num_cuts_at_stage(2));

    Ok(())
```

```rust
fn test_subproblem_solve_forward_pass() -> Result<(), String> {
    let system = create_simple_2stage_system();
```

### Validation Test

```rust
#[test]
fn test_subproblem_consistency_check() -> Result<(), String> {
    let system = create_simple_2stage_system();
    let config = create_test_config();

    let mut builder = SubproblemBuilder::new(&system, &config);
    let subproblem = builder.build_first_stage()?;

    // Run validation checks
    subproblem.validate()?;

    // Check no contradictory bounds
    for i in 0..subproblem.num_variables() {
        assert!(
            subproblem.var_lower_bounds[i] <= subproblem.var_upper_bounds[i],
            "Var {} has invalid bounds: [{}, {}]",
            i, subproblem.var_lower_bounds[i], subproblem.var_upper_bounds[i]
        );
    }

    // Check constraints are well-formed
    for constraint in &subproblem.constraints {
        assert!(
            constraint.lower_bound <= constraint.upper_bound,
            "Constraint {} has invalid bounds",
            constraint.name
        );
    }

    Ok(())
}
```
