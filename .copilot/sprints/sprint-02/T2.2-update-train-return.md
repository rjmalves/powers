## Context

The `train()` function currently returns `Result<(), String>`, discarding all convergence information. With `TrainingResult` struct now available (T2.1), we can return meaningful convergence data.

This is a **breaking change** but necessary for:

- Enabling numerical validation in tests
- Providing users with training insights
- Supporting future features (stopping criteria, diagnostics)

### Implementation Strategy

```rust
pub fn train(
    &mut self,
    num_iterations: usize,
    num_forward_passes: usize,
    saa: &scenario::SAA,
) -> Result<TrainingResult, String> {
    let mut rng = Xoshiro256Plus::seed_from_u64(self.seed);
    let begin = Instant::now();

    // Pre-allocate iterations vector
    let mut iterations = Vec::with_capacity(num_iterations);

    // Track best upper bound
    let mut best_upper_bound = f64::INFINITY;
    let mut best_iteration = 0;

    log::training_greeting(num_iterations, num_forward_passes);
    // ... existing logging ...

    let mut train_handlers: Vec<SddpTrainHandler> = // ... existing code ...

    // Main training loop
    for index in 0..num_iterations {
        let iter_begin = Instant::now();

        // ... existing forward pass code ...
        let avg_forward_cost = utils::mean(&forward_costs);

        // ... existing backward pass code ...
        let lower_bound = // ... existing code ...;

        let iter_time = iter_begin.elapsed();

        // Compute gaps
        let gap = avg_forward_cost - lower_bound;
        let relative_gap = if lower_bound.abs() < 1e-10 {
            f64::INFINITY
        } else {
            gap / lower_bound.abs()
        };

        // Track best upper bound
        if avg_forward_cost < best_upper_bound {
            best_upper_bound = avg_forward_cost;
            best_iteration = index + 1;
        }

        // Store iteration result
        iterations.push(IterationResult {
            iteration: index + 1,
            lower_bound,
            upper_bound: avg_forward_cost,
            forward_costs: forward_costs.clone(), // Or move if not needed later
            gap,
            relative_gap,
            iteration_time: iter_time,
        });

        log::training_table_row(
            index + 1,
            lower_bound,
            avg_forward_cost,
            iter_time,
        );
    }

    log::training_table_divider();
    let total_time = begin.elapsed();
    log::training_duration(total_time);

    // Count cuts in final policy
    let num_cuts = self.future_cost_function_graph
        .get_node(1)
        .ok_or_else(|| {
            "Could not find node 1 for counting cuts".to_string()
        })?
        .data
        .lock()
        .unwrap()
        .cut_pool
        .total_cut_count;

    log::policy_size(num_cuts);

    // Get final bounds
    let final_result = iterations.last()
        .ok_or_else(|| "No iterations completed".to_string())?;

    // Create training result
    Ok(TrainingResult {
        iterations,
        final_lower_bound: final_result.lower_bound,
        final_upper_bound: final_result.upper_bound,
        best_upper_bound,
        best_iteration,
        total_time,
        num_cuts,
        termination_reason: TerminationReason::IterationLimit,
    })
}
```

### Performance Considerations

- **forward_costs clone**: Could use `std::mem::take` if vector not needed after
- **Vec pre-allocation**: Prevents reallocation during loop
- **No extra computation**: Only storing data already computed
- **Gap calculation**: O(1) operation, negligible overhead

### Breaking Change Migration

For existing code calling `train()`:

```rust

    assert!(result.final_upper_bound.is_finite());

    // 2. Check lower bound ≤ upper bound

        "Relative gap too large: {}", relative_gap);

    assert_eq!(result.iterations().len(), num_iterations);
```

### New Convergence Validation Test

```rust
#[test]
fn test_training_result_convergence_history() {
    let system = create_simple_2stage_system();
    let mut sddp = SDDP::new(system, config)?;
    let saa = create_test_saa();

    let result = sddp.train(20, 5, &saa)?;

    // Verify convergence improves over iterations
    let gaps: Vec<f64> = result.iterations()
        .iter()
        .map(|it| it.gap)
        .collect();

    // First gap should be larger than last gap
    assert!(gaps[0] > gaps[gaps.len() - 1]);

    // Check that bounds converge (not oscillate wildly)
    let gap_variance = utils::standard_deviation(&gaps);
    assert!(gap_variance < gaps[0],
        "Gaps should stabilize, not oscillate");
}
```
