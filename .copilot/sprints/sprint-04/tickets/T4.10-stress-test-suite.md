## Technical Notes

### Stress Test Categories

1. **Scale Tests**: Very large problems

   - 100 stages × 100 scenarios
   - 10 stages × 10,000 scenarios
   - 50 stages × 1,000 scenarios

2. **Endurance Tests**: Long-running

   - 10,000 iterations (no convergence check)
   - 24-hour continuous training

3. **Resource Limit Tests**: Until failure

   - Memory exhaustion (increase size until OOM)
   - CPU saturation (thread contention)

4. **Boundary Tests**: Edge of supported range
   - Maximum cuts (100,000+)
   - Maximum state dimension (100+ variables)

### Stress Test Structure

```rust
#[test]
#[ignore]  // Long-running, use --ignored
fn stress_test_large_scale_problem() {
    let config = create_large_scale_config();
    // 50 stages, 1000 scenarios

    let start = Instant::now();
    let start_mem = get_memory_usage();

    let result = run_training(&config);

    let duration = start.elapsed();
    let end_mem = get_memory_usage();
    let mem_used = end_mem - start_mem;

    // Assert success
    assert!(result.is_ok());

    // Record metrics
    println!("Duration: {:?}", duration);
    println!("Memory: {} MB", mem_used / 1_000_000);
    println!("Converged: {}", result.unwrap().converged);

    // Assert reasonable performance
    assert!(duration < Duration::from_secs(3600));  // <1 hour
    assert!(mem_used < 10 * 1_000_000_000);  // <10 GB
}
```

### Memory Monitoring

```rust
#[cfg(target_os = "linux")]
fn get_memory_usage() -> usize {
    let status = std::fs::read_to_string("/proc/self/status").unwrap();
    for line in status.lines() {
        if line.starts_with("VmRSS:") {
            let parts: Vec<&str> = line.split_whitespace().collect();
            return parts[1].parse::<usize>().unwrap() * 1024;  // Convert KB to bytes
        }
    }
    0
}

#[cfg(not(target_os = "linux"))]
fn get_memory_usage() -> usize {
    // Fallback for non-Linux
    0
}
```

### Stress Test Example

```rust
#[test]
#[ignore]
fn stress_test_100_stages_100_scenarios() {
    // Create large problem
    let system = System {
        generators: create_generators(20),
        demands: create_demands(100),
    };

    let graph = Graph::linear(100);  // 100 stages
    let scenarios = create_scenarios(100, 100);  // 100 per stage

    let config = SDDPConfig {
        max_iterations: 100,
        convergence_tolerance: 1e-3,
        ..Default::default()
    };

    // Monitor resources
    let start = Instant::now();
    let start_mem = get_memory_usage();

    // Run training
    let mut sddp = SDDP::new(config, system, graph);
    let result = sddp.train(&scenarios, 100);

    let duration = start.elapsed();
    let end_mem = get_memory_usage();

    // Verify success
    assert!(result.is_ok(), "Training failed: {:?}", result.err());

    // Log metrics
    println!("=== Stress Test: 100 stages × 100 scenarios ===");
    println!("Duration: {:?}", duration);
    println!("Memory: {} MB", (end_mem - start_mem) / 1_000_000);
    println!("Iterations: {}", result.unwrap().iterations);
    println!("Converged: {}", result.unwrap().converged);

    // Assert reasonable performance
    assert!(
        duration < Duration::from_secs(1800),
        "Training took too long: {:?}",
        duration
    );
}
```

### Resource Requirement Formulas

From stress test results, derive formulas:

**Memory (MB)**:

```
Memory ≈ stages × scenarios × state_dim × 0.01
       + num_cuts × 0.000056
       + solver_overhead (100 MB)
```

**Time (seconds)**:

```
Time ≈ iterations × (stages × scenarios × 0.001 + num_cuts × 0.00001)
```

**Maximum problem sizes** (for 64 GB RAM, 32 cores):

- Conservative: 50 stages × 500 scenarios
- Aggressive: 100 stages × 1000 scenarios
- Maximum: 200 stages × 2000 scenarios (may take hours)

### Stress Test Recommendations

Document guidelines like:

**Small system** (<16 GB RAM, <8 cores):

- Max: 20 stages, 100 scenarios
- Training time: <10 minutes

**Medium system** (16-64 GB RAM, 8-32 cores):

- Max: 50 stages, 500 scenarios
- Training time: <1 hour

**Large system** (>64 GB RAM, >32 cores):

- Max: 100 stages, 1000 scenarios
- Training time: <3 hours

**Extreme (server)**:

- Max: 200 stages, 2000 scenarios
- Training time: <24 hours

### Graceful Failure Testing

```rust
#[test]
#[ignore]
fn stress_test_memory_exhaustion() {
    // Start with reasonable size, increase until failure
    for scale in [100, 500, 1000, 5000, 10000, 50000] {
        println!("Testing with {} scenarios...", scale);

        let scenarios = create_scenarios(10, scale);
        let mut sddp = create_test_sddp();

        let result = sddp.train(&scenarios, 10);

        if result.is_err() {
            println!("Failed at {} scenarios", scale);
            println!("Error: {:?}", result.err());

            // Verify graceful error (not panic)
            assert!(matches!(
                result.unwrap_err().kind(),
                ErrorKind::OutOfMemory | ErrorKind::ResourceExhausted
            ));

            break;
        }
    }
}
```

### Common Patterns

**Stress test structure**:

```rust
#[test]
#[ignore]
fn stress_test_<scenario>() {
    let start = Instant::now();
    let start_mem = get_memory_usage();

    // Run test
    let result = run_large_problem();

    let duration = start.elapsed();
    let mem_used = get_memory_usage() - start_mem;

    // Assert and log
    assert!(result.is_ok());
    println!("Duration: {:?}, Memory: {} MB", duration, mem_used / 1_000_000);
}
```

**Memory leak detection**:

```rust
let initial_mem = get_memory_usage();
for i in 0..1000 {
    run_iteration();
    if i % 100 == 0 {
        let current_mem = get_memory_usage();
        println!("Iteration {}: {} MB", i, (current_mem - initial_mem) / 1_000_000);
    }
}
```
