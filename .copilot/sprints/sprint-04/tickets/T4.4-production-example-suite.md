### Example Problem Design

**Example 1 - Trivial Deterministic**:
- 1 thermal generator (cost = 100)
- 2 stages
- Deterministic demand (100 MW)
- No constraints
- Purpose: Verify installation, understand JSON format

**Example 2 - Basic Hydrothermal**:
- 1 hydro (no cost, limited energy), 1 thermal (cost = 100)
- 2 stages
- 3 scenarios (low/med/high inflow)
- Purpose: Introduce stochasticity, storage trade-offs

**Example 3 - Multi-Stage Hydrothermal**:
- 2 hydro reservoirs, 1 thermal
- 12 stages (monthly for 1 year)
- 10 scenarios (historical inflow patterns)
- Purpose: Realistic problem, convergence analysis

**Example 4 - Thermal-Only**:
- 5 thermal generators (different costs/constraints)
- 6 stages
- Constraints: ramp limits, minimum generation
- Purpose: Different problem structure, constraint handling

**Example 5 - Large-Scale**:
- 10+ generators (mixed hydro/thermal)
- 24 stages (hourly for 1 day, or monthly for 2 years)
- 100+ scenarios
- Purpose: Performance, scalability, realistic size

### Running Examples Script

```bash
#!/bin/bash
# run_all.sh

set -e

echo "Running all examples..."

for example in 01-trivial-deterministic 02-basic-hydrothermal 03-multistage-hydrothermal 04-thermal-only 05-large-scale; do
    echo ""
    echo "==================================="
    echo "Running example: $example"
    echo "==================================="

    cd "$example"
    cargo run --release -- config.json
    cd ..
done

echo ""
echo "All examples completed successfully!"
````

### Creating Problem JSON Files

Use existing `example/` as template:

- `config.json`: SDDP algorithm configuration
- `system.json`: Physical system (generators, reservoirs)
- `graph.json`: Scenario tree structure
- `scenario.json`: Stochastic data (inflows, demands)

### Common Patterns

**Trivial problem**:

```json
{
  "generators": [
    {
      "name": "thermal1",
      "type": "thermal",
      "cost": 100.0,
      "capacity": 1000.0
    }
  ],
  "demands": [{ "stage": 0, "value": 500.0 }]
}
```

**Hydrothermal problem**:

```json
{
  "generators": [
    {
      "name": "hydro1",
      "type": "hydro",
      "cost": 0.0,
      "capacity": 200.0,
      "reservoir_capacity": 1000.0
    },
    {
      "name": "thermal1",
      "type": "thermal",
      "cost": 100.0,
      "capacity": 500.0
    }
  ]
}
```
