## Technical Notes

### HiGHS Solver Time Breakdown

Typical LP solve phases:

1. **Presolve**: Reduce problem size (10-20% of time)
2. **Simplex iterations**: Main optimization work (60-80% of time)
3. **Postsolve**: Recover original problem solution (5-10% of time)
4. **Basis extraction**: Get dual values (5% of time)

### Profiling Approach

```rust
use std::time::Instant;

struct SolverProfile {
    presolve_time: Duration,
    simplex_time: Duration,
    postsolve_time: Duration,
    total_time: Duration,
    iterations: usize,
}

fn profile_solve(solver: &mut Solver) -> SolverProfile {
    let start = Instant::now();

    // If HiGHS has built-in profiling, use it
    solver.enable_profiling();
    solver.solve();
    let profile = solver.get_profile();

    // Otherwise, measure manually
    SolverProfile {
        total_time: start.elapsed(),
        ..profile
    }
}
```

### Warm-Start Measurement

```rust
fn benchmark_warm_start(problem: &Problem) {
    let mut solver = Solver::new();
    solver.load_problem(problem);

    // Cold start
    let cold_start = Instant::now();
    solver.solve();
    let cold_time = cold_start.elapsed();

    // Extract basis
    let basis = solver.get_basis();

    // Warm start (modify problem slightly)
    problem.update_rhs();
    let warm_start = Instant::now();
    solver.load_basis(&basis);
    solver.solve();
    let warm_time = warm_start.elapsed();

    println!("Cold: {:?}, Warm: {:?}, Speedup: {:.2}×",
             cold_time, warm_time, cold_time.as_secs_f64() / warm_time.as_secs_f64());
}
```

### Key Metrics

| Metric             | Description                | Target |
| ------------------ | -------------------------- | ------ |
| Solver time %      | Solver time / total time   | <80%   |
| Warm-start speedup | Cold time / warm time      | >2×    |
| Simplex iterations | Avg iterations per solve   | <100   |
| Basis reuse %      | Warm-starts / total solves | >90%   |

### Expected Findings

Based on SDDP best practices:

- **Warm-start**: 2-5× speedup over cold-start
- **Presolve**: Beneficial for first solve, skip for warm-starts
- **Dual simplex**: Usually better for SDDP (changing RHS)
- **Basis quality**: Degrades over iterations, periodic refresh needed

### Optimization Opportunities

High-priority candidates:

1. **Aggressive warm-start**: Use basis from previous stage/scenario
2. **Disable presolve for warm-starts**: Save 10-20% time
3. **Batch subproblem solves**: Amortize overhead
4. **Lazy constraint generation**: Solve relaxed problem first

### Solver Configuration Recommendations

**Default (Balanced)**:

```rust
SolverConfig {
    presolve: true,
    simplex_strategy: SimplexStrategy::Dual,
    primal_feasibility_tolerance: 1e-7,
    dual_feasibility_tolerance: 1e-7,
    time_limit: None,
}
```

**High Performance (Expert)**:

```rust
SolverConfig {
    presolve: false,  // Disable for warm-starts
    simplex_strategy: SimplexStrategy::Dual,
    primal_feasibility_tolerance: 1e-6,  // Relax slightly
    dual_feasibility_tolerance: 1e-6,
    time_limit: Some(Duration::from_secs(10)),  // Cap outliers
}
```

**Memory Constrained**:

```rust
SolverConfig {
    presolve: true,  // Reduce problem size
    simplex_strategy: SimplexStrategy::Primal,  // Less memory
    max_iterations: 1000,  // Prevent runaway
}
```

### Benchmark Structure

```rust
use criterion::{black_box, criterion_group, criterion_main, Criterion, BenchmarkId};

fn solver_config_benchmark(c: &mut Criterion) {
    let mut group = c.benchmark_group("solver_configs");

    let configs = vec![
        ("default", default_config()),
        ("no_presolve", no_presolve_config()),
        ("dual_simplex", dual_simplex_config()),
        ("primal_simplex", primal_simplex_config()),
    ];

    for (name, config) in configs {
        group.bench_with_input(
            BenchmarkId::new("subproblem_solve", name),
            &config,
            |b, config| {
                let problem = create_test_subproblem();
                b.iter(|| {
                    let mut solver = Solver::with_config(config.clone());
                    solver.load_problem(&problem);
                    black_box(solver.solve())
                });
            },
        );
    }

    group.finish();
}
```
