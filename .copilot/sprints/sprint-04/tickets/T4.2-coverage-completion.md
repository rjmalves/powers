## Technical Notes

### Running Coverage

```bash
# Install tarpaulin (if not already installed)
cargo install cargo-tarpaulin

# Generate coverage report
cargo tarpaulin --out Html --output-dir target/coverage

# View report
open target/coverage/index.html  # macOS
xdg-open target/coverage/index.html  # Linux
```

### Test Organization

Follow existing patterns:

- Unit tests: In same file as code (`#[cfg(test)]` module)
- Integration tests: In `tests/` directory
- Fixtures: In `tests/fixtures/`
- Common utilities: In `tests/common/`

### Test Naming Convention

```rust
#[test]
fn test_<function_name>_<scenario>_<expected_outcome>() {
    // Example: test_forward_pass_empty_scenarios_returns_error
}
```

### Error Path Testing Pattern

```rust
#[test]
fn test_input_validation_negative_capacity_returns_error() {
    let config = SystemConfig {
        generators: vec![Generator {
            capacity: -100.0,  // Invalid
            ..Default::default()
        }],
        ..Default::default()
    };

    let result = System::from_config(&config);
    assert!(result.is_err());
    assert_eq!(result.unwrap_err().kind(), ErrorKind::InvalidInput);
}
```

### Edge Case Testing Pattern

```rust
#[test]
fn test_forward_pass_empty_scenarios() {
    let mut sddp = create_test_sddp();
    let scenarios = vec![];  // Empty

    let result = sddp.forward_pass(&scenarios);
    assert!(result.is_ok());
    assert_eq!(result.unwrap().len(), 0);
}

#[test]
fn test_backward_pass_single_stage() {
    let mut sddp = create_single_stage_problem();
    let result = sddp.backward_pass();

    // Single stage has no future, should handle gracefully
    assert!(result.is_ok());
}
```

### Testing Locally

```bash

cargo tarpaulin --out Html --output-dir target/coverage

# Run specific test file
cargo test --test <test_file>

# Run specific test
cargo test <test_name>

# Run with output
cargo test -- --nocapture
```

### Common Patterns

**Error path test**:

```rust
#[test]
fn test_function_invalid_input_returns_error() {
    let result = function(invalid_input);
    assert!(result.is_err());
}
```

**Edge case test**:

```rust
#[test]
fn test_function_empty_input() {
    let result = function(vec![]);
    assert!(result.is_ok());
}
```

**Panic test**:

```rust
#[test]
#[should_panic(expected = "index out of bounds")]
fn test_function_panics_on_invalid_index() {
    function(invalid_index);
}
```
